# Changelog

## 0.3.0 — First public release

- Nested main quests, side quests and steps, progress and collapsible task trees.
- A focus timer from 1 to 180 minutes, with quick presets and an unwinding thread animation.
- A movable, resizable quest window above other apps, including compact mode.
- Rosary rewards, configurable reward amounts and a custom reward shop.
- Product images with square cropping, rosary purchases and purchase history.
- English and Russian interface; English starter quests and a Pepsi Bottle reward.
- Ten-second undo, export, previous-save recovery and up to seven daily snapshots.
- Optional encrypted local Wi-Fi pairing with the Android notification companion.
- Standalone Windows x64 executable with .NET included.
- Keyboard navigation, quiet hover states and optional motion, sound and weathering.

The Android companion currently uses Russian. Physical-device notification and camera behavior still needs testing.
